# بسته اسناد اجرایی حافا

این بسته برای آغاز رسمی پروژه در **۲۴ مرداد ۱۴۰۵** آماده شده است.

| فایل | کاربرد |
|---|---|
| `00_برنامه_مبنای_فاز_اول_حافا.md` | برنامه رسمی، تقویم ۱۶ هفته‌ای، نقاط کنترل و وابستگی‌ها |
| `01_دستورجلسه_آغاز_پروژه.md` | دعوت و اداره جلسه Kick-off در ۲۴ مرداد |
| `02_فرم_فهرست_و_اولویت_فرآیندها.md` | دریافت فهرست فرآیند همه مدیریت‌ها و انتخاب موج اول |
| `03_فرم_جلسه_کشف_فرآیند.md` | ثبت وضع موجود و داده‌های لازم برای BPMN |
| `04_گزارش_هفتگی_پروژه.md` | گزارش هفتگی مدیر پروژه به کمیته راهبری |

پیش از جلسه آغاز، نسخه‌های تکمیل‌شده فرم‌های ۲ و ۵ از نمایندگان واحدها دریافت شود. خروجی جلسه آغاز باید شامل احکام، فهرست نهایی اعضا، روز جلسات ثابت، سقف فرآیندهای موج اول و سیاست سطح دسترسی ویکی باشد.
